# werk

werk is a visual layer over Claude Code. It shows a project's decisions as a map of cards, a board of tickets, and a chat with a live agent that changes the map.

## Install

1. Install Bun at the pinned version: `curl -fsSL https://bun.sh/install | bash -s "bun-v$(cat .bun-version)"`.
2. Run `make install`.

## Start

Run `make dev`. Run `make` to list every task, including each check.
