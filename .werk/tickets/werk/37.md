## What to build

The overseer is plain code inside the agent runner, with every limit a parameter. It watches each pipeline session.

A builder's permission ask goes to a classifier agent with the tool, the input and the ticket; no verdict means deny, and every answer goes to the session log. The silence clock starts at the session's first event, and every event and every partial-message token resets it; 60 seconds of silence with no tool call in flight cancels the session. A tool call in flight is frozen when the CPU time of its child processes stays flat for 60 seconds, or when it has no process and the stream stays quiet; a failed process probe counts as unknown and is recorded. Every 5 minutes a classifier gets the brief and the tool calls since its last verdict and says looping or not; no verdict means not looping, and it is skipped when no new call came. Each act is a line in the session log.

A cancelled builder pass starts a fresh pass with the reason in its brief and counts against the cap. A cancelled grader or reviewer is a failed step.

## Acceptance criteria

- [ ] With the silence limit set to milliseconds, a scripted stall after the first event cancels the pass, and the next brief says it was silent.
- [ ] A slow start with no event before the limit is not cancelled for silence.
- [ ] A scripted ask is answered by the classifier role, and a classifier with no verdict makes the ask denied.
- [ ] A looping verdict cancels the pass and puts the reason in the next brief.
- [ ] A failed probe cancels nothing and leaves a probe-failed line.
