## What to build

Typing `/` at the start of a word anywhere in the composer opens a menu of the commands the agent accepts; typing `#` at the start of a word opens a card search over ids and titles. Arrows move, Enter or Tab inserts the choice, Escape closes. A backtick right before the trigger character turns the menu off, so inline code stays plain.

## Acceptance criteria

- [ ] Typing `/` after a space opens the command menu, and Enter inserts the chosen command.
- [ ] Typing `#pr` opens a list of cards whose id or title matches, and Enter inserts the id with its #.
- [ ] A backtick before `#` opens no menu.
