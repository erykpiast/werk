## What to build

Pasting or dropping an image uploads it at once. The server checks the type (PNG, JPEG, GIF, WebP) and the 20 MB cap and stores it in the project's attachments folder, outside version control, answering with the file name. The chip shows a spinner, then the thumbnail; a refused image shows its reason on the chip. The paste inserts `[Image #N]` at the caret, and removing a chip deletes its token and renumbers the rest.

Enter waits while an upload runs. The send carries only the stored paths, and the turn tells the agent which token is which path and to open each with its own file read. The server serves only files inside the attachments folder; an empty or traversing name answers 404.

## Acceptance criteria

- [ ] A pasted PNG shows a chip with a thumbnail and the token [Image #1].
- [ ] A 25 MB image shows its refusal on the chip and is not sent.
- [ ] Removing chip 1 of two renumbers the other to [Image #1].
- [ ] The fake agent's launch record shows the turn with the image path, not its bytes.
- [ ] A request for an image with an empty name answers 404 and the server stays up.
