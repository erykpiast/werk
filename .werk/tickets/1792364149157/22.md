## What to build

A deterministic overseer process reads the event stream of each build pass that werk starts, in real time. It acts on three signs. A permission ask that nobody answers: the overseer answers it itself, and no verdict means deny. An unintentional loop: a classifier agent checks every 5 minutes whether the agent repeats the same call or the same failing check, and no verdict means not looping. Silence: no new event for 60 seconds, unless a tool call is still working; then the overseer cancels the session and a fresh pass starts. The overseer tells a working tool call from a frozen one, and a failed process probe leaves the call unknown, not frozen.

Every limit is a parameter, so tests run the 60-second and 5-minute limits in milliseconds with the fake agent.

## Acceptance criteria

- [ ] A fake agent that raises a permission ask gets an answer from the overseer, and the pass goes on.
- [ ] A fake agent that goes silent past the silence limit with no working tool call is cancelled, and a fresh pass starts.
- [ ] A fake agent with a long, working tool call is not cancelled for silence.
- [ ] A fake classifier that says "looping" stops the pass. A classifier with no verdict does not.
- [ ] Each overseer action appends an event to the run's record.
