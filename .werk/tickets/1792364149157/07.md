## What to build

An agent runs the quote operation with a session and a text. The command line searches that session's transcript for the text, verbatim. On exactly one match, it proposes an excerpt node that records the message index, the span, the speaker, and the session, linked supported_by from the card that cites it. The excerpt enters as a ghost, like every other kind.

Text that does not match exactly, or that matches more than one message, fails with a message that says which case happened. The tool never guesses.

## Acceptance criteria

- [ ] A quote with one exact match proposes an excerpt with the message index, span, speaker, and session.
- [ ] The excerpt is linked supported_by from the citing card and waits for the ✓.
- [ ] A quote with no exact match exits non-zero and writes no event.
- [ ] A quote that matches two messages exits non-zero and writes no event.
- [ ] The excerpt shows in the card view with its speaker and session.
