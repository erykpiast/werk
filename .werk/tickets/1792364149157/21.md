## What to build

A run starts when a person starts it. The merge loop takes the finished tickets one at a time through a merge queue. For each ticket it makes a temporary tree of the run's tree plus the ticket and runs the checks on it. Red: nothing merges, and the ticket goes back to the builder loop with the failure. Green: the ticket merges into the run's branch, and the held-out set runs on the run's tree. A red held-out step files a follow-up ticket, and the merge stands.

Up to 3 unblocked tickets build at once, each off the run branch tip. Build ends when every ticket is merged and every held-out step passes.

## Acceptance criteria

- [ ] Two tickets that are green alone merge one after the other, each after green checks on the run's tree plus the ticket.
- [ ] A ticket whose checks are red on the merged tree does not merge, and its next builder pass holds the failure.
- [ ] After each merge the held-out set runs. A red step files a follow-up ticket, and the merged commit stays on the run's branch.
- [ ] No more than 3 tickets build at the same time.
- [ ] The run ends only when every ticket is merged and every held-out step is green.
