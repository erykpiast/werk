## What to build

When an agent sets a card to decided, the command line runs a program check of the card's facts before it appends the status event. If a fact is missing, the command fails, appends nothing, and prints the exact command that supplies the fact. An amend of a decided card runs the same facts again. Card creation and the other statuses are not checked, and the text of a card is not checked.

## Acceptance criteria

- [ ] Setting a card to decided with a missing fact exits non-zero, appends no event, and prints one command that fixes it.
- [ ] Running the printed command and then setting decided again succeeds.
- [ ] An amend of a decided card that removes a required fact is refused by the same check.
- [ ] Adding a card and setting it open are not checked.

## Checks

- `make test`
- `make typecheck`
