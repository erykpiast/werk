## What to build

The inner build loop works end to end with no person in the middle except at the gates. In one test at the command-line seam, against a temporary project and git repository with the fake agent first on the PATH, a decided subtree goes through the plan, a run at the feature tier, the builder loop with checks, grader and review, the merge loop with the held-out set, and the overseer, until G2 opens on a green final tree. The browser seam covers the map, card rendering, the chat pane, multichat and the board; the command-line seam covers every map write and the whole pipeline. No test reaches a real agent.

## Acceptance criteria

- [ ] The end-to-end test runs the whole loop with every time limit set to milliseconds and finishes in under a minute.
- [ ] The test asserts on what a person sees: exit codes, the run branch and its commits, the merged tree, the log and the run's records.
- [ ] A scripted held-out failure in the test produces a follow-up ticket, and G2 opens only after it is built and merged.
- [ ] No test in the suite starts a real Claude Code process.
