## What to build

Build runs on two levels: a builder loop per ticket and a merge loop per run. The merge loop takes finished tickets one at a time. It makes a temporary tree of the run's tree plus the ticket and runs the checks on it. Red: nothing merges, and the ticket goes back to the builder loop with the failure. Green: the ticket merges into the run's tree. Then the held-out set runs on the run's tree. A red step files a follow-up ticket in ready, and the merge stands. Build ends when every ticket is merged and every held-out step passes.

## Acceptance criteria

- [ ] Two tickets that are each green alone but conflict in a check together: the second one does not merge and goes back to building with the failure.
- [ ] A green ticket merges, and the run branch holds its commits.
- [ ] After each merge the held-out set runs, and a red step files a follow-up ticket while the merge stays on the run branch.
- [ ] The run ends only when every ticket is merged and every held-out step is green.

## Checks

- `make test`
- `make typecheck`
- `make lint`
