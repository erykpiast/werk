## What to build

Each agent session sends its permission asks on its pipe, the same protocol the chat pane uses. The overseer answers every ask. No ask waits for a person.

For each ask, the overseer starts a short classification agent with the tool, its input, and the ticket's brief. The classifier says allow, or deny with a comment. The overseer sends the answer back. On a deny, the agent gets the comment and continues without that call. The overseer waits for the classifier with a timeout. A timeout is a deny, with the timeout as the comment.

Every ask, the answer, and the comment go to the event log.

## Acceptance criteria

- [ ] A fake agent's ask that the fake classifier allows is answered allow, and the call runs.
- [ ] A deny reaches the agent with the classifier's comment.
- [ ] A classifier that does not answer in time gives a deny with the timeout as the comment.
- [ ] Each ask and answer is one event in the log, with the comment.
