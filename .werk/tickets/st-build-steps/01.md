## What to build

The project gets a Makefile with three targets: `test`, `typecheck`, and `lint`. Each target runs the command that the project uses today. `werk loop` uses these three targets as its default checks when no `--check` is given. A check line names a target, never a tool.

This is the prefactor for the rest of the spec. Every later ticket's checks are these targets.

## Acceptance criteria

- [ ] `make test`, `make typecheck`, and `make lint` each exit 0 on the current tree.
- [ ] Each target exits non-zero when its tool fails. A test proves it for `make test` with a failing test in a temporary repository.
- [ ] `werk loop` with no `--check` runs the three targets, in that order.
- [ ] The help text for `werk loop` names the default checks.

## Checks

- `make test`
- `make typecheck`
- `make lint`
