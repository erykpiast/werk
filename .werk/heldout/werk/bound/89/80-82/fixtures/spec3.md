# Spec: reopen a card

## User Stories

1. As a person, I want to reopen a decided card, so that I can change my mind.
2. As a person, I want the dependent cards to show a stale mark, so that I check them.
3. As a person, I want the stale mark to name the reopened card, so that I find the cause.
