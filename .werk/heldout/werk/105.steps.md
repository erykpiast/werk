Scenario: An ask in a background tab stays on its own tab
Given a person has two conversation tabs open, "#alpha" and "#beta"
And the person reads the "#alpha" tab
When the agent in "#beta" asks for permission to run a command
Then the "#beta" chip blinks yellow
And the "#alpha" pane shows no ask and no new line
When the person opens the "#beta" tab
Then the ask bar of "#beta" shows the permission ask
When the person allows the ask in that ask bar
Then the agent in "#beta" continues its turn with the permission given
And the agent in "#alpha" receives no answer and shows no change
And the "#beta" chip stops blinking yellow

Scenario: A parked tab with an ask makes the '…' button blink
Given a person has six conversation tabs open, so one tab is parked in the '…' menu
And the person reads one of the visible tabs
When the agent in the parked tab asks for permission
Then the '…' button blinks yellow
And the pane the person reads shows no ask
When the person opens the parked tab from the '…' menu and answers the ask in its ask bar
Then the '…' button stops blinking

Scenario: A running tab shows a dot on its chip and its home card, also with a background agent
Given a person opened a conversation on the card "#beta" and switched to another tab
When the person sends a message in "#beta" and the agent starts a turn that also starts a background agent
Then the "#beta" chip shows a running dot
And the "#beta" card in the map tree shows a running dot
When the main turn in "#beta" ends but the background agent still runs
Then the "#beta" chip and the "#beta" card in the tree still show the running dot
When the background agent ends
Then the "#beta" chip and the "#beta" card in the tree show no running dot

Scenario: A crashed background child shows red and puts a line in the focused pane
Given a person has two conversation tabs open, "#alpha" and "#beta"
And the person reads the "#alpha" tab
When the agent process in "#beta" crashes
Then the "#beta" chip shows a red dot
And the "#alpha" pane shows a line that names "#beta" and says that its agent died

Scenario: Red wins over yellow when a child with a pending ask dies
Given a person has two conversation tabs open, "#alpha" and "#beta"
And the person reads the "#alpha" tab
And the agent in "#beta" asks for permission, so the "#beta" chip blinks yellow
When the agent process in "#beta" crashes before the person answers
Then the "#beta" chip shows a red dot and does not blink yellow
And the "#alpha" pane shows a line that names "#beta"
