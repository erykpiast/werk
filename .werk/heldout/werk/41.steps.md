Scenario: The executable alone serves the map and the client
Given a fixture project with a map that has three cards
And the werk executable for this platform is copied alone into an empty folder
And no Bun install, no source folder, and no built client folder are next to it
When I start werk from that executable in the fixture project
And I open the werk address in a browser
Then the page loads the werk client without errors
And the map shows the three cards from the fixture project
And I open one card and its full text shows

Scenario: A prompt built in the executable names the executable
Given werk runs from the executable at a known path in an empty folder
And the fixture project has a map
When I send a chat message that asks the agent to add a card to the map
Then the prompt that the agent receives names the path of the executable for werk commands
And the prompt does not contain a runtime name followed by a source path
And the agent runs a werk command by that path and the card appears in the map in the browser

Scenario: Commands that werk shows and child processes name the executable
Given werk runs from the executable at a known path
And the fixture project has a map
When I start a build pass from the browser
Then each command that werk shows me names the executable path
And the process list shows werk's child processes started by the executable path
And no child process runs through a runtime and a source path

Scenario: A checkout serves the client and prompts as before
Given a checkout of werk with the dependencies installed
And the fixture project has a map with three cards
When I start werk from the checkout
And I open the werk address in a browser
Then the client loads and the map shows the three cards
And a chat message to the agent gets a reply
And the prompt for the agent names the running werk command, not a source path from a different place

Scenario: The build produces one executable for each platform
Given a clean checkout of werk
When I run `make build`
Then the build finishes without errors
And the output has four executables: macOS ARM, macOS Intel, Linux ARM, and Linux Intel
And no Windows executable exists
And the executable for my platform starts and serves the client for the fixture project
