Scenario: Focusing a tab moves the map to that tab's card
Given two conversation tabs are open, tab A on card #alpha and tab B on card #beta
And tab A is focused and the map shows card #alpha
When the user clicks the chip for tab B
Then the map shows card #beta
And the scope above the composer shows #beta
When the user sends a message in tab B
Then the reply in tab B is about card #beta, not card #alpha

Scenario: Each tab restores its own map position after a switch
Given two conversation tabs are open, tab A on card #alpha and tab B on card #beta
And tab A is focused
When the user navigates the map from #alpha to a different card #gamma
Then the scope above the composer shows #gamma
When the user clicks the chip for tab B
Then the map shows card #beta
When the user clicks the chip for tab A
Then the map shows card #gamma, not card #alpha
And the scope above the composer shows #gamma
And the map in tab B still shows #beta when the user focuses tab B again

Scenario: An unsent draft stays with its tab
Given two conversation tabs are open, tab A and tab B
And tab A is focused
When the user types "half-written note about alpha" in the composer and does not send it
And the user clicks the chip for tab B
Then the composer in tab B does not contain "half-written note about alpha"
When the user clicks the chip for tab A
Then the composer in tab A contains "half-written note about alpha"
And no message with that text appears in either conversation
