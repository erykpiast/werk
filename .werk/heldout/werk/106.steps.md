Scenario: An agent lists the sibling conversations of its project
Given a project with three conversations, each started from a different home card
And each conversation has its own session id
When the agent runs the convos verb
Then the agent sees one line for each of the three conversations
And each line shows the conversation's session id and its home card

Scenario: An agent reads what a sibling said about a keyword
Given a project with two conversations
And the sibling's session log holds spoken messages and tool calls
And two spoken messages and one tool call mention the word "pricing"
When the agent runs the convos verb and copies the sibling's session id
And the agent runs the recall verb with that session id and the keyword "pricing"
Then the agent sees the two spoken messages that mention "pricing"
But the agent sees no tool call and no tool result
And the agent sees no message that does not mention "pricing"

Scenario: An agent reads a whole sibling conversation without a keyword
Given a sibling conversation whose session log holds user messages, assistant replies, and tool calls
When the agent runs the recall verb with the sibling's session id and no keyword
Then the agent sees the user messages and assistant replies in their original order
But the agent sees no tool call and no tool result

Scenario: An agent asks for a session that does not exist
Given a project with one conversation
When the agent runs the recall verb with a session id that no conversation of the project has
Then the recall verb tells the agent that it does not know the session
And the recall verb exits with a non-zero status

Scenario: Switching tabs does not push news from other tabs
Given a person has two conversation tabs open in werk
And the person sends a message in the first tab and gets a reply
When the person focuses the second tab
Then the second tab's agent receives no message about the first tab
And the second tab's transcript shows no new message
When the person sends a message in the second tab
Then the second tab's agent receives only the person's message
