## What to build

After each merge the held-out set starts on that merge's commit in the background, with the steps of every merged ticket of the subtree including the one just merged; steps of tickets still building, merging or archived stay out. The merge queue takes its next ticket at once. An older held-out run is not stopped by a newer merge; each result belongs to its own commit, and only the result on the main line's final tip opens G2. A held-out result event records each step's state on the done ticket whose merge it followed.

A red run groups its red steps by source ticket and files one follow-up ticket per group, citing the cards of its source ticket, with the full text of its steps as its stories, its own retry cap, and no step author. A follow-up starts in ready and the running loop builds it. A red step that an open follow-up already carries files nothing. The merge stands. A not-run step files nothing. A binder error that stays at the end of the run ends it waiting for a person. The red badge stays on the merged ticket after its follow-up goes green.

## Acceptance criteria

- [ ] A merge starts a held-out run and the next merge does not wait for it.
- [ ] Red steps from two source tickets file exactly two follow-ups, each citing its own ticket's cards.
- [ ] A step that is red again while its follow-up is open files nothing.
- [ ] A step of a ticket that is not merged yet is not in the run.
- [ ] G2 opens only on a green held-out result for the final tip.
