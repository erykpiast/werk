## What to build

A pure renderer turns card text into safe HTML. It escapes everything first, splits fenced blocks out before any inline rule, renders an unclosed fence while text streams, and handles inline code, bold, italic, strikethrough, links, headings, lists, block quotes and rules. A variant for tiles renders inline Markdown with links and images as their text.

The reference linker takes a set of known ids (ghosts included, removed and discarded ones excluded). `#id` links any known id; a bare id links only if it has a hyphen or a colon; a code span links only when it holds nothing but an id. No reference starts after a word character, slash, second #, hyphen, colon or ampersand; fenced blocks, headings and URL fragments stay text. Every link shows as `#id` in a monospace face and points at `/map/<id>`. An unknown id stays as written.

The highlighter colours fenced code by any common tag name in any case (sh, shell, zsh, bash; ts, tsx, typescript, js; json, jsonc), boxes it with sideways scroll and a corner label for any tag; an unknown or missing tag renders plain.

## Acceptance criteria

- [ ] `#al-diff`, bare `al-diff` and a code span holding `al-diff` all render as the same `#al-diff` link.
- [ ] `--al-diff`, `##al-diff`, `&al-diff` and a code span holding a command stay text.
- [ ] A reference to an id not in the known set stays plain text.
- [ ] A fence tagged `zsh` gets the shell grammar; a fence tagged `cobol` renders plain with its label.
- [ ] Script tags in card text are escaped.
- [ ] Each renderer module has its own test file and passes the coverage gate.
