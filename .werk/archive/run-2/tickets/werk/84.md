## What to build

After a merge, a user path that must work does not work on the merged product. Make it work. Each path, word for word:

Scenario: Commands that werk shows and child processes name the executable
Given werk runs from the executable at a known path
And the fixture project has a map
When I start a build pass from the browser
Then each command that werk shows me names the executable path
And the process list shows werk's child processes started by the executable path
And no child process runs through a runtime and a source path
