## What to build

The overseer is plain code inside the runner that starts each build pass, grader, reviewer, step author and binder session; chat sessions get none. It asks the agent for partial messages and counts every streamed token as an event, without writing tokens to the session file. The silence clock starts at the agent's first event: no event for 60 seconds after that cancels the session, unless a tool call is in flight. For a call in flight, it reads the CPU time of the agent's child processes: growing CPU time means working; flat CPU for 60 seconds cancels it; a call with no process of its own cancels like silence. A probe that cannot read the process table counts as unknown, cancels nothing, and is logged. Only the wall-clock cap stops a session that never starts.

A builder's permission ask goes to a classifier agent with the role ask-classifier, on the model the role table names, with the tool, its input and the ticket; it allows or denies with a comment; no verdict means deny. Every 5 minutes, a classifier with the role loop-classifier gets the brief and the tool calls since its last verdict and says looping or not; no verdict means not looping, and it is skipped when no new call came. Looping cancels the session and the next pass gets the reason. A cancelled builder pass commits its edits, skips the checks, counts against the cap, and the next brief says why. A silent grader or reviewer fails as a step with silence as the reason. Every act is a line in the session file and the live log. All limits are parameters in milliseconds for tests.

## Acceptance criteria

- [ ] A fake that prints one event then stalls is cancelled after the silence limit, and the next pass starts.
- [ ] A fake that is slow to start but then keeps printing is never cancelled for silence.
- [ ] A tool call whose process burns CPU past the limit is not cancelled; a flat one is.
- [ ] A failed process probe cancels nothing and is logged.
- [ ] A builder ask with a fake classifier that denies reaches the agent as a deny with the comment.
- [ ] A fake classifier answering looping cancels the pass and its reason appears in the next brief.
- [ ] The verdict logic is a pure module that passes the coverage gate.
