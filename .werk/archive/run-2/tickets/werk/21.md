## What to build

The session id from the agent's init event, the model, the advisor and the last context fill are saved beside each conversation and restored at start, so a restart resumes the same session on the same model and the pie shows the same fill. A stored session id is cleared only on Claude Code's own "No conversation found with session ID" message; then a new session starts and the waiting message is replayed. Any other early exit keeps the id, retries once, and then says "Your message was not delivered. Send it again." The agent's whole stderr shows in the pane; a failure that a retry cannot fix (a login problem, a bad flag) skips the retry.

The header row above the composer has a model selector (Sonnet, Opus, Sonnet with Opus advisor, pinned model ids) and a context pie: tokens of the latest assistant message over the window size, blue under 33%, yellow from 33%, red from 66%. Before the first turn the window comes from the model. Clicking the pie opens a popover with the percentage and Clear context. A model switch or a clear restarts the child on purpose without a crash message; both refuse while a turn runs.

## Acceptance criteria

- [ ] After a server restart, the conversation resumes its session, shows its model and the same pie value.
- [ ] A dead stored session id is cleared and the message replays in a new session.
- [ ] A crash with another error keeps the session id, retries once, then asks to send again.
- [ ] The pane shows every line of the agent's error output.
- [ ] Switching the model while a turn runs is refused; when idle, it restarts with no crash message.
