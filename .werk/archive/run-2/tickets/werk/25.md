## What to build

The server holds one context per listed project: map, conversations, agents and builds. The project list is stored once per user outside every project. Starting werk in a folder while a server runs adds the folder, opens it in the browser and exits. Addresses carry the project. A project is named by its folder; a duplicate name adds its parent folder in brackets.

The switcher sits at the left of header row 1, before the breadcrumbs: the current project with a menu arrow, a menu that lists every project (a busy dot when an agent turn runs, missing and grey when the folder is gone, a × on hover) and "Add project…". Add opens the operating system's folder dialog from the server; a test replaces the dialog with a scripted fake of the same kind as the fake agent. On a machine with no supported folder dialog, add follows the proposal #werk-v0-add-project-fallback until a person rules on it. A folder with no map gets an empty map; a folder with no git repository is refused with an offer to initialise one, done only on agreement. With an empty list, the page shows only Add project. Remove takes a project off the list without touching its folder; with a running turn it names the turns and asks first. A missing project does not open.

Switching keeps the other project's agents running. Display settings are shared; the open card and view are kept per project, and a first visit opens the home card. In dev mode werk's own checkout is always listed, cannot be removed, and is not written to the stored list.

## Acceptance criteria

- [ ] Adding a second project through the fake dialog lists it, and switching opens its own map.
- [ ] A chat turn running in project A continues while project B is open, and A shows a busy dot.
- [ ] Removing a project leaves its folder and map on disk; adding it again shows the same map.
- [ ] A deleted folder shows as missing and does not open.
- [ ] Each project reopens at the card it was left on, and its chat log shows its newest message.
- [ ] Starting werk in a new folder while a server runs adds the folder and exits.
