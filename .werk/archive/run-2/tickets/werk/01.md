## What to build

A developer clones the new, empty v0 repository and runs `make` with no arguments. It prints every task target with a one-line description. Each target first checks the installed Bun version against the pinned one and stops with both versions and the install hint on a mismatch, then installs the locked packages when the package file or lockfile changed, then calls a package script.

The targets are dev, lint, typecheck, test, test-coverage, e2e, check (all checks in merge-loop order), fix, build and help. Lint runs Biome with its recommended and React rules over all code. Typecheck runs TypeScript 7 in strict mode with checked index access and no emit. Test runs `bun test` on four parallel workers with a 15-second default limit per test. Test-coverage runs each listed pure file's own test file alone with coverage on, keeps only that file's lines, and fails any listed pure file under 90% lines; a listed file with no own test file counts as 0% and the output names the missing test file. A listed file with no executable lines passes. The list of pure files is explicit and starts with one small pure helper and its test, so the gate has something to judge.

The repository also gets a README (what werk is, how to install and start it), AGENTS.md (how to run, which target runs each check, where server and client code live, that decisions go on the map, and to list and follow the build-rule cards), a one-line CLAUDE.md that imports AGENTS.md, shared Claude Code settings that allow every make target and the werk command line but keep accept, remove and restore behind a question, a personal-settings file in the ignore list, one post-edit hook that formats and lints the edited file only, and no project skills or MCP servers. Nothing is copied from the prototype.

## Acceptance criteria

- [ ] `make` with no target prints the list of targets, each with a description.
- [ ] Every target stops with a clear message when the installed Bun differs from the pinned version.
- [ ] A fresh clone with no installed packages runs `make test` and installs the locked packages first.
- [ ] `make lint`, `make typecheck`, `make test` and `make test-coverage` pass on the scaffold.
- [ ] Deleting the own test file of a listed pure file makes `make test-coverage` fail and name the missing test file.
- [ ] The coverage output prints one line per listed pure file with its percentage.
- [ ] The shared Claude Code settings allow the make targets and ask before accept, remove and restore.
- [ ] Editing a source file runs the format-and-lint hook on that file only and reports remaining errors.
