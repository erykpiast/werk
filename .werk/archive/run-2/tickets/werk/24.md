## What to build

In the composer, a word starting with `/` opens a menu of the agent's slash commands, and a word starting with `#` opens a menu of cards by id and title; a backtick right before the trigger turns the menu off. Arrows and Enter pick an entry.

Pasting or dropping an image inserts `[Image #N]` at the caret and a chip with a spinner. The page uploads the image at once with the token; the server checks the type (PNG, JPEG, GIF, WebP) and the 20 MB cap, stores it in the project's attachments folder, outside version control, and answers with its name; the chip then shows the thumbnail the server serves. A refused image shows its reason on its chip. Removing a chip deletes its token and renumbers the rest. Enter waits for running uploads, then sends the text with each stored path; the turn maps each token to its path and tells the agent to open each image. The image route serves only files inside the attachments folder, and a request with an empty or traversing name answers 404 without harming the server.

## Acceptance criteria

- [ ] Typing `#wer` shows matching cards; picking one inserts its id.
- [ ] A pasted PNG shows a thumbnail, and the sent turn maps `[Image #1]` to a stored path.
- [ ] A 25 MB image shows a refusal on its chip and is not sent.
- [ ] Removing chip 1 of two renumbers the other token to `[Image #1]`.
- [ ] A request for an image with an empty name answers 404 and the server keeps running.
