## What to build

Every chat agent that werk starts gets the card wording rules in its instructions: a card describes its own subject, not the session that wrote it; it holds no edit history and no source of its text; it names behaviour and concepts, not files, functions or line numbers; it states rules, not one module's results. No program checks card text. The instructions are prompt text only, and every chat child gets the same text.

## Acceptance criteria

- [ ] The fake agent records the instructions it received, and they contain each wording rule.
- [ ] A new conversation and a resumed conversation both receive the rules.
- [ ] Adding a card whose text names a file is not refused by any program check.
