## What to build

No tab is fed a diff of what a sibling said. When an agent needs it, it pulls. werk knows the session id and home card of every conversation, so the command line lists the sibling conversations of the project and reads one of them from its session log on disk, including turns that compaction dropped. The map is the other channel: an agent reads a card from the map before it writes it, so a stale belief in its context never becomes a wrong write.

## Acceptance criteria

- [ ] The list command prints every conversation with its session id and home card.
- [ ] The read command prints the text of a given sibling conversation from its session log, and can filter it by a keyword.
- [ ] Switching tabs sends no message and no context to the focused tab's agent.
- [ ] The chat agent's instructions tell it to read a card from the map before it writes the card.
