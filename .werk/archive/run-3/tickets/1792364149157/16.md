## What to build

Every build run is a feature run. The first event of a run is a tier event that records feature. G1, G2, and G3 each wait for a person. No gate auto-passes.

The run does not read a tier from the conversation, and it has no escalation path: no spoken tier is parsed and no run is re-rated.

## Acceptance criteria

- [ ] The first event of every run is a tier event with the value feature.
- [ ] A run stops at G1 until a person passes the gate, and the same at G2.
- [ ] A request text that names a tier ("just build it", "keep it simple") does not change the tier of the run.
- [ ] No command or option re-rates a live run.
