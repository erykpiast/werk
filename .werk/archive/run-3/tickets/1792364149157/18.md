## What to build

After the grader passes, five reviewer agents read the diff at the same time, each in a fresh context with one area: design, maintainability, tests, security and dependencies, and performance. A finding has a severity (CRITICAL, HIGH, MEDIUM, LOW), a file and a line, an impact, and a fix. A finding points at the diff or at code the diff directly affects.

A CRITICAL or HIGH finding fails the pass, and the next builder pass gets the findings. MEDIUM and LOW findings do not block; the loop records them per ticket. v0 builds no trend report over them.

## Acceptance criteria

- [ ] A pass that clears the grader starts five reviewer agents, one per area, each with only the diff.
- [ ] A fake reviewer that returns a HIGH finding fails the pass, and the next pass's prompt holds that finding.
- [ ] MEDIUM and LOW findings are recorded in the run's record and do not fail the pass.
- [ ] No trend report or trend alert is produced.
