## What to build

Nothing builds before the person starts the run. Inside an active run the person has four actions on the board. Reorder tickets within ready. Archive a ready or blocked ticket after a confirmation that says an agent can restore it. Trigger the build of one ready ticket, by the trigger icon or by a drag into building. Stop a building ticket by a drag back into ready. These are the only manual moves. Tickets are not edited on the board; the drawer says to ask an agent, who runs the ticket-set checks again.

A building ticket with a live session pulses, and stops the moment the session ends. The drawer of a building ticket shows a live log preview of the session above the slice, in a fixed-height scrolling area. The preview drops when the ticket leaves building.

## Acceptance criteria

- [ ] Before the run starts, no ticket builds, and the trigger is not available.
- [ ] A drag within ready changes the build order, and the next ticket to build follows it.
- [ ] Archive shows only on ready and blocked tickets, asks for confirmation that says it can be restored, and removes the ticket from the board.
- [ ] The trigger icon and a drag into building each start the build of one ready ticket.
- [ ] A drag of a building ticket into ready stops its session and puts it in ready.
- [ ] A building ticket pulses while its session runs and stops pulsing when the session ends.
- [ ] The drawer of a building ticket shows the live log, and the log is gone after the ticket leaves building.
- [ ] The board has no control that edits a ticket's text.
