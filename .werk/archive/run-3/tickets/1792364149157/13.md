## What to build

The conversation manager reports running, waiting, and dead for each conversation. Each chip carries a state dot. A running tab shows a pulsing dot on its chip and on its home card in the tree. A tab whose main turn ended but whose background agent still runs reads as running.

A permission ask is answered only on its own tab, in its own ask bar. Each conversation keeps one ask at a time. The asking tab's dot blinks yellow, and the '…' button blinks too when that tab is hidden behind it.

A dead child shows a red dot, and a line in the pane the person looks at, with the dead tab's name. Red wins over yellow on every surface.

## Acceptance criteria

- [ ] A tab with a running turn shows a pulsing dot on its chip and on its home card in the tree.
- [ ] A tab with a finished turn and a running background agent still shows running.
- [ ] A permission ask from a background tab does not show in the focused tab's pane. The background chip blinks yellow.
- [ ] When the asking tab is parked, the '…' button blinks.
- [ ] A dead child in a background tab shows a red dot and a line in the focused pane that names the tab.
- [ ] A tab that has an ask and a dead child shows red.
