## What to build

When a card moves to decided, the command line runs a program check on the card's facts first: who decides, its depends_on basis or a stated lack of one, its weighed options or a recorded unchallenged flag, and its kill criteria. If a fact is missing, the move refuses and prints the exact next command that supplies it.

The check reads the held edges of a ghost the same way it reads live edges, so a ghost proposed as decided obeys the same rule. An amend of a decided card — a reopen and a decide in one step — runs the same facts again. Card creation and the text of a card are not checked.

## Acceptance criteria

- [ ] A move to decided on a card that lacks a fact exits non-zero and prints the next command that fixes that fact.
- [ ] Running the printed command and then the move again succeeds.
- [ ] A ghost with held edges that supply every fact moves to decided. A ghost without them refuses.
- [ ] An amend of a decided card that removes a required fact refuses.
- [ ] An add with no facts succeeds as a proposal; the check fires only at the move to decided.
