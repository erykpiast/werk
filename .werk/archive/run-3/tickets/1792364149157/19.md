## What to build

The builder loop for one ticket runs each pass as implement, check, grade, review. The checks stop at the first red. The grader runs only on green checks, and the review only after the grader passes. A fail at any step starts a new pass at implement, with the failure in its input. There is no separate fix step.

A retry cap stops a loop that does not converge. The default cap is 5 passes. At the cap the loop stops and keeps the branch.

## Acceptance criteria

- [ ] A pass with a red check does not start the grader or the reviewers.
- [ ] A pass with a failed grade does not start the reviewers.
- [ ] A fail at check, grade, or review starts the next pass with that failure in its prompt.
- [ ] A ticket that never goes green stops after 5 passes by default, exits non-zero, and keeps its branch.
- [ ] The cap is a parameter, and a test sets it to 2.
