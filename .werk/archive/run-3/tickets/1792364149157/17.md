## What to build

After the checks pass, a grader agent reads the pass's diff against each decided card in the ticket's depends_on closure. For each card it returns a score from 1 to 5, where 3 passes, and the gap: what the diff does wrong against the card, with the file, line, or test that shows it.

A score under 3 on any card fails the pass. The next builder pass gets the gaps together with the brief.

## Acceptance criteria

- [ ] The grader prompt holds one judgement line per decided card in the depends_on closure, and no line for a card outside it.
- [ ] A fake grader that returns 2 on one card fails the pass, and the next pass's prompt holds that card's gap.
- [ ] A fake grader that returns 3 or more on every card passes the grade step.
- [ ] The run's record holds the score and the gap of each card for each pass.
