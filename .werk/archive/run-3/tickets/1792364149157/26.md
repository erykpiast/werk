## What to build

A person picks a decided subtree and starts a build. The inner build loop runs the whole path with no person in the middle, apart from the gates: the plan writes a spec and tickets; the merge loop builds each ticket in its builder loop with the checks, the grader, and the review; it merges ticket by ticket and runs the held-out set after each merge; and the overseer watches every pass. Build ends when every ticket is merged and every held-out step is green. v0 has no trend report.

## Acceptance criteria

- [ ] A build over a fixture subtree with the fake agents writes a spec, tickets, pass commits, and merged commits on the run's branch, and ends at G2.
- [ ] The overseer watches every pass the build starts.
- [ ] A held-out step made red by one ticket files a follow-up ticket, and the build ends only after the follow-up makes it green.
- [ ] The test runs at the command line against a temporary git repository with every time limit in milliseconds.

## Checks
