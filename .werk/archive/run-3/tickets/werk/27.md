## What to build

The chat header row has a model selector (Sonnet, Opus, Sonnet with the Opus advisor, pinned model ids) and a context-fill pie. A switch is refused while a turn runs and the control is disabled then; when idle, werk stops the child on purpose and restarts it on the same session with the new model. The pie shows the last assistant message's tokens over the window size read from the conversation's own model entry, blue under a third, yellow from a third, red from two thirds. Its popover offers Clear context, which drops the session and the transcript and restarts the child; the map is untouched. Model, advisor and fill are saved beside the session and come back after a restart.

A server restart resumes the stored session. Only Claude Code's "No conversation found" message clears the session id, and then the waiting message is replayed into a new session. Any other crash shows the child's whole error, retries once, then says the message was not delivered. A failure that a retry cannot fix, such as a bad flag or a missing login, is not retried.

## Acceptance criteria

- [ ] Switching to Opus while idle restarts the fake child on the same session with the Opus model id.
- [ ] After a server restart the selector and the pie show the saved model and fill before any message.
- [ ] A stored session that no longer resolves is cleared, and the waiting message reaches a new session.
- [ ] A crash with a login error shows the full error and is not retried.
- [ ] Clear context leaves the map's log unchanged.
