## What to build

The chat child runs in auto permission mode, and werk does not classify tool calls. A call the engine cannot resolve arrives as a control request; the turn waits while the pane shows the ask bar: the tool, the call as a code block, the engine's reason as-is, and Allow once, Deny, and Always allow only when the engine attached a widening suggestion, shown inline. One click disables the bar. Several asks stack; Cmd+Enter allows and Escape denies the first. Every answer is appended to the ask log.

Always allow stores the engine's own suggestions for that conversation only, and its next child starts with them.

A question tool call shows as a form: lettered options with descriptions, a free-text field, Submit answer and Decline. The picks reach the model as one plain line per question, sent as the reason of the refusal, and the log does not record that as a failure. Picks survive a redraw.

## Acceptance criteria

- [ ] A scripted ask blocks the fake's turn until Allow, and Deny returns a refusal message.
- [ ] Always allow appears only for an ask with a suggestion, and the next child starts with the stored rule.
- [ ] A rule allowed in one project's conversation does not apply in another project.
- [ ] A question form returns "For "<question>": <label>" to the agent.
- [ ] Each answered ask adds one line to the ask log.
