## What to build

When a finished reply ends with a line `Next: say "<phrase>"` or `Next: reply "<phrase>"`, the pane shows a button with that phrase. A click sends the phrase as a normal message with the open card and leaves the draft alone. The next message removes all earlier buttons.

The conversation keeps a count of background tasks, the length of the last full task list the agent sent, and zero when the child exits. While the count is above zero, a line under the chat log says a background agent runs, and the project counts as busy in the switcher.

A child that exits when werk did not stop it, after any automatic retry, is dead: its open asks and background tasks drop, the pane shows the error, and the switcher marks the project dead until the next child starts. A stop for a model switch, a cleared context or a server shutdown is not a death.

## Acceptance criteria

- [ ] A reply ending in `Next: say "merge it"` shows a "merge it" button, and a click sends that text.
- [ ] A scripted task list of two items, then of none, shows the background line and then removes it.
- [ ] A fake child that exits with code 1 marks the project dead in the switcher, and the next message clears the mark.
- [ ] A model switch never marks the project dead.
