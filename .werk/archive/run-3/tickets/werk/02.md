## What to build

`make test-coverage` runs the unit tests with coverage and then the coverage gate. The gate reads an explicit list of pure files. For each listed file it runs that file's own test file alone, with coverage on, and counts only the lines of that pure file that its own test runs. Lines that another file's test runs do not count.

The gate prints one line per listed file with its percentage and exits 1 when any file is under 90%. A listed file with no own test file counts as 0% and the line names the missing test file. A listed file with no executable lines passes. The list is a set: each file appears once and the order has no effect on the verdict.

Plain `make test` does not run the gate.

## Acceptance criteria

- [ ] A listed pure file at 100% from its own test passes, and the gate prints its percentage.
- [ ] A listed pure file whose own test is deleted fails at 0%, even when another file's test runs all of its lines, and the output names the missing test file.
- [ ] A listed file under 90% makes the gate exit 1.
- [ ] A listed file of type declarations only passes.
- [ ] `make test` alone never runs the gate.
