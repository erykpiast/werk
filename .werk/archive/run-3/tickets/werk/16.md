## What to build

One pure Markdown renderer serves card bodies, whys, notes and chat. It escapes everything first, splits fences first, and renders an unclosed fence while text streams. It renders inline code, bold, italic, strike, links, headings, lists, quotes and rules.

A card reference becomes a link only for an id the map can open now, a ghost included, and always shows as the id with a # in front. With the # any known id links; without it, an id links only when it holds a hyphen or a colon. A code span links only when it holds nothing but an id. A hash after a word character, a slash, a second #, a hyphen, a colon or an ampersand is not a reference; a fence and a heading are left alone. A tile mode renders the same inline marks with references shown but not linked.

A fence is boxed with a sideways scroll and highlighted by any common tag name in any case; an unknown tag renders plain, and a tag shows as a corner label. A backtick span in a title renders as code.

## Acceptance criteria

- [ ] `al-diff`, a code span holding only al-diff, and #al-diff all render as a link labelled #al-diff.
- [ ] `--al-diff`, `##al-diff` and `&al-diff` stay text.
- [ ] A reference to a removed card stays plain text.
- [ ] A fence tagged `zsh` is highlighted as shell, and one tagged `cobol` renders plain with its label.
- [ ] Script in card text renders as text.
- [ ] The renderer passes the coverage gate.
