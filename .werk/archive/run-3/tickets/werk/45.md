## What to build

A person drags ready tickets to reorder them. The drawer header of a ready, blocked or building ticket has an archive button; it asks for confirmation and says that the ticket is never deleted and an agent can restore it. Archiving a building ticket is the one way to end its build, and the builder loop stops within about a second. A merging or done ticket has no archive. There is no edit of a ticket on the board.

Inside an active run, a ready ticket with no open blocker has a trigger icon; the icon, or a drag from ready into building, starts that ticket early, and it goes through the same merge queue. With no active run, the trigger is not offered. No other drag between columns is allowed. Every action needs the server token and appends a board event.

## Acceptance criteria

- [ ] Dragging ticket 3 above ticket 2 in ready keeps that order after a reload.
- [ ] Archiving asks first; after it the ticket leaves the columns and the restore verb brings it back.
- [ ] Archiving a building ticket ends its scripted build within about two seconds and keeps its branch.
- [ ] Dragging a ready ticket into building inside an active run starts its build.
- [ ] A drag from done to ready does nothing.
