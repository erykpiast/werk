## What to build

The quote verb finds the given text in the chat log of a conversation, the log beside the decision log. It counts occurrences in every spoken message, text that the person typed or the agent wrote, never tool calls, tool results or tooling text. It writes an excerpt only when the count is exactly one. Otherwise it fails, writes nothing, and says which case it found: no match, a match in N messages, or N matches in one message.

The excerpt points at the conversation, the session, the message position among all lines counted from zero, the span inside that one message, the speaker and the time, and keeps the quoted words. The quote creates the excerpt and the supported_by link from the citing card as one event, as a ghost. A plain add of an excerpt, and a retitle or text edit of one, is refused before and after the accept. A note on it works.

## Acceptance criteria

- [ ] A quote that occurs once writes one event with the excerpt and its link, and show prints the words, speaker and span.
- [ ] A quote that occurs in two messages fails, names two messages, and appends nothing.
- [ ] A quote that occurs twice in one message fails and names the count.
- [ ] Text that occurs only in a tool result gives no match.
- [ ] Adding an excerpt by hand and editing an excerpt's text are refused.
- [ ] The quote matcher passes the coverage gate.
