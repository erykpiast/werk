## What to build

Each project has one continuous conversation, docked in the right pane, that keeps going while the person moves across the map. The server runs one long-lived Claude Code child for it over stream-json, with the launch options of the chat role.

A send is one request with the text, the open card and the turn name. The first turn on a card carries a compact description of the card built from the map; every later turn on the same card carries a one-line reminder. The whole tree is the home card's page, so a turn from it names the home card. The server keeps sent turns in order; each reply part belongs to the oldest open turn, the end line closes it, and an exit ends every open turn. A message whose turn has not started shows "waits for the reply above".

The reply streams in as Markdown, with a status line (thinking or running, tool name, seconds, tokens) and the end line with duration and cost. A run of tool calls collapses into one line with the latest call and a count. Finished blocks replace their streamed form by the block's own order, not the array index. The chat header row sits right above the composer.

## Acceptance criteria

- [ ] A message sent on a card reaches the fake chat agent with that card's description, and a second one carries the reminder line.
- [ ] A scripted reply that runs an add makes the card appear in the map while the reply streams.
- [ ] A second message sent during a reply shows the waiting mark, and every part of the first reply stays above it.
- [ ] Three tool calls in a row show as one collapsed line with the count 3.
- [ ] A send without the token is refused.
