## What to build

The switcher sits at the left of header row 1, before the breadcrumbs, and shows the current project's name with a menu arrow. The menu lists every project with its folder, a busy dot while an agent turn runs, a grey "missing" row for a folder that is gone, and a × on hover except for the dev-mode entry. A divider and "Add project…" end the list.

"Add project…" makes the server open the operating system's folder dialog. A folder with no map gets an empty map; a folder with no git repository is offered an init, done only on agreement. With an empty list, werk opens one page with the same action.

Display settings are shared by all projects. Each project keeps its own open card and view, so a switch opens where the person left that project; a first open shows its home card.

## Acceptance criteria

- [ ] Clicking another project opens its map, and switching back opens the card that was open before.
- [ ] A project with a running turn shows a busy dot; a missing folder shows grey and does not open.
- [ ] Adding a folder with no git repository asks before it initialises one.
- [ ] With an empty list, the start page offers "Add project…".
