## What to build

Each project keeps one append-only log of map events. The command line is the only way to write it. A write checks its events against the folded map in order and appends all of them or none; an event that breaks a map rule (unknown card, duplicate id, second parent, cycle) is refused with the rule it breaks.

The fold is a pure function from events to the map: nodes with their latest words and status, live edges, held ghost edges, and the place for the marks that later tickets derive. Every read replays the whole log and records how long the fold took. An event in a committed log that breaks a rule is set aside, listed as a problem with its place in the log, and the events after it still fold.

The command line loads its verbs by registration: each verb lives in its own module and registers itself, and the help output lists the registered verbs. The start-up starts the chosen verb and does not wait for it; a callback exits with the verb's code. Every argument that names a card accepts the id with or without one leading hash sign; text arguments keep theirs.

This ticket adds two verbs. Add proposes a card, an option or a source as a ghost under an optional parent in one event, prints "proposed", refuses a decided status and a second add with the same id. Show prints one card with its words, status, parent, links and rollup line, and marks a ghost as proposed.

## Acceptance criteria

- [ ] Adding a card under a parent appends exactly one event, and show prints the card under that parent as proposed.
- [ ] A second add with the same id exits non-zero, names the rule, and appends nothing.
- [ ] Add with a decided status is refused.
- [ ] A hand-written bad line in the log is listed as a problem, and the cards after it still show.
- [ ] Show accepts `#id` and `id` as the same card; a title that starts with a hash keeps it.
- [ ] The help output lists every registered verb, and a new verb module adds itself with no edit to a shared list.
- [ ] The fold is on the pure-file list and passes the coverage gate.
