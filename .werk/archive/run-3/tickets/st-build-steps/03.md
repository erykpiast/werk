## What to build

After the checks pass, the builder loop runs a grader step. A fresh grader agent gets the ticket's diff and the decided cards in its closure (#lp-prod-judge). For each card it returns a score from 1 to 5 and the gap between the diff and the card, with the file, line, or test that shows the gap. A score of 3 or more passes.

Every card passes: the step is green. Any card fails: the pass fails, and the next builder pass gets the failed cards and their gaps with the brief. Output the loop cannot parse counts as a fail, with the parse error as the gap.

The verdict for each card goes to the event log.

## Acceptance criteria

- [ ] With a fake grader that gives one card a 2, the next builder pass gets that card's id and gap, and the build does not end.
- [ ] With a fake grader that gives every card 3 or more, the build ends green.
- [ ] Malformed grader output fails the pass with the parse error in the next pass's input.
- [ ] The grader runs only after the checks are green. A red check skips it.
- [ ] Each card's score and gap is one event in the log.
