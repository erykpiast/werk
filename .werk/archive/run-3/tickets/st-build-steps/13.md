## What to build

Every 5 minutes, the overseer starts a classifier agent for each running agent. The classifier gets the ticket's brief and the tool calls since its last verdict, not the whole log. It returns "looping" or "not looping" and a reason in one or two sentences.

The overseer waits with a timeout. No verdict counts as "not looping".

On "looping", the overseer cancels the agent. The builder loop starts a fresh pass, and the classifier's reason goes into that pass's brief.

The 5 minutes is a parameter. Each verdict goes to the event log.

## Acceptance criteria

- [ ] The classifier's input holds only the tool calls since the last verdict.
- [ ] A fake classifier that says "looping" cancels the agent, and the next pass's brief has the reason.
- [ ] A classifier that times out leaves the agent running.
- [ ] A test sets the interval to milliseconds.
