## What to build

A plain overseer process starts with a build and watches every agent session the build starts: builders, the grader, and the reviewers. It has no model inside it. It reads each session's streamed events as they arrive.

A session that writes no new event for 60 seconds is stuck. The overseer cancels it. For a builder, the builder loop starts a fresh pass, and the brief says the last pass was cancelled for silence. A grader or reviewer that goes silent is cancelled and counts as a failed step with the same reason.

A tool call that is still in flight is not silence. This ticket only records which calls are in flight. Deciding about them is a later ticket.

The 60 seconds is a parameter. Every overseer action goes to the event log.

## Acceptance criteria

- [ ] A fake agent that stops writing events is cancelled after the limit, and a fresh pass starts.
- [ ] The fresh pass's brief says the last pass was cancelled for silence.
- [ ] A fake agent with a tool call in flight past the limit is not cancelled by this rule.
- [ ] A test sets the limit to milliseconds.
- [ ] The overseer runs as its own process, and the build still ends if the overseer is not running.
