## What to build

The map has one store: an append-only log of events. The command line is the only write path. An agent adds a card, links two cards with a typed link, retitles a card, and sets its status. Each command appends one event and never rewrites or deletes an earlier one.

A pure fold turns the event list into the map state: each card with its latest title, body, why line, status and links. The command line, the server read API and the browser all read the same fold of the same log. The browser draws the refines tree of the fold and refetches it when the server pushes "changed" on the live event channel. The open card lives in the location hash. No view edits a drawn card in place.

## Acceptance criteria

- [ ] Each map command appends exactly one event to the end of the log, and the earlier events are byte-for-byte unchanged.
- [ ] After a retitle, the map and `show` print only the new title, and the old title is still in the log.
- [ ] The browser draws the refines tree from the fold, and a card added from the command line appears in an open page without a manual reload.
- [ ] No control in the page changes a card except by a request that appends an event.
- [ ] The fold is a pure function of the event list and is on the pure-file list of the coverage gate.
- [ ] Opening the page with a card id in the location hash opens that card.
