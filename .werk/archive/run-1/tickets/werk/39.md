## What to build

`werk quote <card> --session <id> --text "..."` reads the session's transcript, finds the text verbatim in one message, and proposes an excerpt node: the message index, the span, the speaker, and the session. The excerpt is supported_by the card that cites it, and it enters as a ghost like every other node.

Text that does not match exactly fails. Text that matches more than one message fails. The tool never guesses.

## Acceptance criteria

- [ ] A quote that matches one message once proposes an excerpt ghost with the message index, the span, the speaker, and the session.
- [ ] The excerpt is linked supported_by the citing card, and the link is held until the accept.
- [ ] A quote with one changed character exits non-zero and appends nothing.
- [ ] A quote found in two messages exits non-zero, names both message indexes, and appends nothing.
- [ ] A quote against a session id with no transcript exits non-zero.
