## What to build

After a merge, a user path that must work does not work on the merged product. Make it work. Each path, word for word:

Scenario: A script can ask for permission, stall, repeat a tool call, and die mid-turn
Given a fake agent is first on the PATH under the name of the real agent
And a script tells the fake to emit a permission ask, then emit nothing for 200 milliseconds, then emit the same tool call three times, then exit with code 137 before the turn ends
When the test runs the agent with a prompt
Then the test reads a permission ask event first
And no event arrives for at least 200 milliseconds after the ask
And the test then reads three identical tool call events
And the output has no turn result event
And the agent exits with code 137

## Acceptance criteria

- [ ] A user can follow "A script can ask for permission, stall, repeat a tool call, and die mid-turn" from start to end
