## What to build

`werk say <id> "..."` appends a note to the card's thread in the log. `werk inbox` prints every thread with notes, the newest last, so an agent catches up from the command line.

The server has a note route. It appends a note to the card's thread and copies the line `re #<id> "<title>": <text>` to the clipboard. The browser never calls this route.

## Acceptance criteria

- [ ] `werk say` appends one note event, and `werk inbox` prints it under the card id and title.
- [ ] `werk say` on an unknown id exits non-zero and appends nothing.
- [ ] A request to the note route appends the note and puts the reference line on the clipboard (the test reads a fake clipboard).
- [ ] No client code calls the note route.
