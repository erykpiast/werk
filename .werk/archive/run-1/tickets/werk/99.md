## What to build

A chat pane sits beside the map and never resets as the person moves through the map. Enter in the composer sends the text, any pasted images, the open card from the location hash, and the active conversation tab to the server.

The conversation manager runs one Claude Code child per conversation, in the chat role, and speaks to it over stream-json. The child lives across many messages: each message is one turn on the same child. Each turn starts with a line that names the card the person looks at. The reply streams back over the live channel and renders in the pane through the same Markdown renderer and card link rule as a card body.

The server has no note route. A person writes through the composer, and the agent writes notes on a card with the note verbs.

## Acceptance criteria

- [ ] Enter sends one request that carries the text, a pasted image, the open card and the active tab.
- [ ] The fake agent's scripted reply appears in the pane piece by piece as it streams.
- [ ] The launch record shows the chat role, and the fake's recorded turn input starts with the open card's id.
- [ ] A second message goes to the same child process, and the open card in its first line is the card open at that moment.
- [ ] A card id in the reply is a link that opens that card on the map.
- [ ] The server answers no note route.
