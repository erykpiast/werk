## What to build

After a merge, a user path that must work does not work on the merged product. Make it work. Each path, word for word:

Scenario: A user starts werk in a project and sees the empty map shell
Given a project directory with no cards in it
When the user runs `werk serve` in that project directory
And the user opens the address that the server prints in a browser
Then the browser shows a page that React renders
And the page shows an empty map shell with no cards on it
And the user sees no error on the page or in the server output

Scenario: An agent edits a server module while a live session runs, and the session survives
Given the user starts werk with the dev command in a project directory
And the user notes the process id of the server
And a long-lived agent child is running from a chat session that started before the edit
When the agent saves a change to a server module
Then the server output shows that the changed module reloaded
And the server output says that it reuses the live server and does not listen a second time
And the process id of the server is the same as before the edit
And the long-lived agent child from before the edit is still alive
And a new browser connection to the live channel sees the same server state as before the edit
And no second server or second agent child starts
