## What to build

A deterministic overseer reads each build session's event stream in real time. It acts on three signs: a permission ask that nobody answers, which it answers itself, where no verdict means deny; an unintentional loop, which a classifier agent judges every 5 minutes by asking whether the agent repeats the same call or the same failing check, where no verdict means not looping; and silence, where no new event arrives within the limit while no tool call is still working, which cancels the session and starts a fresh pass. The overseer tells a working tool call from a frozen one, and a failed process probe leaves the call unknown, not frozen. Every limit is a parameter, so tests set the 60-second and 5-minute limits to milliseconds.

## Acceptance criteria

- [ ] A fake session that asks for a permission gets an answer from the overseer, and the pass goes on.
- [ ] A fake session that emits no event past the silence limit is cancelled, and a fresh pass starts.
- [ ] A fake session with a long tool call that is still working is not cancelled for silence.
- [ ] A fake classifier that reports a loop ends the session, and a fresh pass starts.
- [ ] Every overseer action is an event in the run's record.
- [ ] A fake classifier with no verdict does not stop the session.
- [ ] An ask with no overseer verdict is denied.
- [ ] A tool call whose process probe fails is treated as unknown and not cancelled as frozen.
