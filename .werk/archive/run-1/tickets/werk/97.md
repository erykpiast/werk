## What to build

A test writer scripts a permission ask followed by a stall, repeated tool calls or a crash, all before anybody answers. An ask step prints the permission request and does not wait. The next steps play at once. The turn waits for its open asks only just before it prints its final result.

With an input channel, the fake takes the answer to an ask from that channel. With no input channel, it denies the ask at the end of the turn. A crash step with an ask open exits with no tool result and no final result, the way a real agent that dies does.

Each pause step adds a 20 ms margin to its length, so a test never measures a silence shorter than the script asks for.

## Acceptance criteria

- [ ] A script of ask, pause, tool call: the pause and the tool call play before any answer is sent.
- [ ] An answer sent on the input channel settles the ask, and the final result follows it.
- [ ] With no input channel, the ask is denied at the end of the turn and the final result follows.
- [ ] A script of ask then crash exits with no tool result and no final result in the output.
- [ ] A pause of 100 ms keeps the output silent for at least 120 ms.
