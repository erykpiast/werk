## What to build

The chat pane sits beside the map. Enter in the composer sends the text, the pasted images, the open card from the location hash, and the active conversation tab to the server's chat route. The conversation manager holds one Claude Code child for the conversation and speaks stream-json to it. Each turn starts with a line that names the open card. The reply streams back over the live channel and the pane renders it with the Markdown renderer, so card links work in chat too.

The child gets werk's agent instructions. They state the card wording rules: a card's words describe its subject, not the session, and name no file, function, or line.

## Acceptance criteria

- [ ] With the fake agent, Enter sends a turn. The fake records the text, the image, and a first line that names the open card.
- [ ] The fake's scripted reply appears in the pane while the turn runs, before the turn ends.
- [ ] A `#card-id` in the reply renders as a link.
- [ ] After a navigation to a second card, the next turn names the second card.
- [ ] The instructions that the child gets contain the card wording rules.
- [ ] A turn sent while the child is dead shows the error in the pane and the server stays up.
