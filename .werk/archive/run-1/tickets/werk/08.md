## What to build

The chat pane sits beside the map. Enter in the composer sends the text, any pasted images, the open card from the location hash and the active conversation to the server. The server hands the message to that conversation's Claude Code child over stream-json, and the reply streams back over the live event channel as it runs. Each turn starts with the card the person looks at. The person's messages and the agent's replies render with card links. An agent reads a card's thread and writes a note to it from the command line. The server has a note route that appends a note and copies a `re #<id> "<title>": <text>` line to the clipboard; the browser never calls it.

## Acceptance criteria

- [ ] Enter sends one request that carries the text, pasted images, the open card and the active conversation.
- [ ] With the fake agent on the PATH, the reply text appears in the pane in more than one piece before the turn ends.
- [ ] The message the agent receives starts with the open card.
- [ ] A `#known-id` in a reply renders as a link.
- [ ] A note written from the command line shows in the card's thread, and the thread command prints it.
- [ ] The note route appends a note event, and no browser code calls it.
- [ ] The fake agent receives all four parts of the request.
- [ ] The first line of each turn names the open card's id and title.
