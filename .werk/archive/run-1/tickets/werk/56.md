## What to build

The build scheduler starts up to 3 unblocked ready tickets at the same time, in the board's ready order. It reads each ticket's touches line. Two tickets build at the same time only when their touches lines name no common module. A ticket that shares a module with a running build waits for it, and the next ticket in order that shares no module starts. The limit of 3 is a parameter.

## Acceptance criteria

- [ ] Four unblocked ready tickets with disjoint touches lines: three build at the same time, and the fourth starts when one ends.
- [ ] Two tickets that name one common module never build at the same time.
- [ ] A ticket that waits for a shared module does not stop a later ticket with no shared module from starting.
- [ ] A ticket with an unmet blocker does not start.
