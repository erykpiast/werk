## What to build

The overseer runs inside the headless agent runner and reads each pass's event stream as it comes. It is a deterministic process. It acts on three signs. A permission ask that nobody answers: the overseer answers it itself, and with no verdict it denies. No new event for 60 seconds, where every token the model writes counts as an event, and with no tool call in flight: the overseer cancels the session and a fresh pass starts. Every 5 minutes, a classifier agent decides whether the pass loops on the same tool call or the same failing check: a loop cancels the pass, after one warning. A tool call in flight that a process probe shows as frozen is cancelled. A failed probe leaves the call unknown, not frozen.

Every limit is a parameter, so the tests set them to milliseconds.

## Acceptance criteria

- [ ] A fake that asks a permission question and waits gets an answer from the overseer, and the pass goes on.
- [ ] A fake that stays silent past the silence limit is cancelled, and a fresh pass starts with the reason in its prompt.
- [ ] A fake that streams tokens with no tool call is not cancelled for silence.
- [ ] A fake that repeats one tool call is warned, then cancelled when the fake classifier still says it loops.
- [ ] A fake classifier that returns no verdict leaves the pass running.
- [ ] A frozen tool call is cancelled, and a call whose process probe fails is not.
