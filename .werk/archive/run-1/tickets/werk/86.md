## What to build

The held-out set is built before the merge loop, as its own slice. A step author agent starts when the builder starts and writes Given, When, Then steps from the ticket. A binder agent turns the steps into tests and never makes a test pass. The steps and tests live where the builder's worktree cannot see them, and never enter its prompt.

A held-out run command runs the bound tests on the run's tree. A failed step gives the builder the text of the failed step, not the test code. The gate verb refuses to open G2 while any held-out step is red.

## Acceptance criteria

- [ ] A fake author and binder produce steps and tests outside the builder's worktree.
- [ ] No builder prompt or worktree file holds any held-out step text.
- [ ] A held-out run on a tree with a scripted break reports the red step.
- [ ] The builder's next prompt holds the failed step's text.
- [ ] The gate verb exits non-zero while a step is red and opens G2 when all are green.
