## What to build

Cross-tab memory is pulled, not pushed. werk knows the session id of every conversation it started, so an agent does not search for a sibling by keyword.

The convos verb lists every conversation of the project with its session id and its home card. The recall verb reads one sibling's session log from disk on demand, with an optional keyword filter, and prints its spoken messages without tool noise. No tab is fed a diff of what changed since its fork.

## Acceptance criteria

- [ ] The convos verb prints each conversation's session id and home card.
- [ ] The recall verb prints the messages of a fixture session log that match a keyword, and leaves out tool calls.
- [ ] The recall verb on an unknown session id exits non-zero.
- [ ] Focusing a tab sends no message about other tabs to its child.
