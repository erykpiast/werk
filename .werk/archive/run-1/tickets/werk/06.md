## What to build

An agent quotes a conversation by giving the text and the session. The quote operation searches that session's transcript for the text, exactly. On one match it proposes an excerpt node that records the message index, the span, the speaker and the session, linked supported_by the card that cites it. Text that does not match exactly, or that matches more than one message, fails, writes nothing, and says which case happened. The tool never guesses.

## Acceptance criteria

- [ ] A quote that matches one message once writes an excerpt with the message index, span, speaker and session, and the excerpt is a ghost.
- [ ] A quote with one changed character fails with no event.
- [ ] A quote that occurs in two messages fails with no event and names the ambiguity.
- [ ] The span on the excerpt selects the quoted text in the transcript exactly.
- [ ] The excerpt is linked supported_by from the citing card and waits for the ✓.
- [ ] The excerpt shows in the card view with its speaker and session.
