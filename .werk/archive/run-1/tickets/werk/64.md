## What to build

An agent sets a card to decided. Before the status event is appended, the contract check tests the fixed set of facts on the log: who decides, the depends_on basis, the rejected options, and the kill criteria. If a fact is missing, the verb exits non-zero, appends nothing, and prints the exact next command that fixes the card.

The check reads the held edges of a ghost the same way it reads live edges, so a ghost proposed as decided obeys the same rule.

A decided card is frozen. A change to it is an amend: a reopen and a decide in one step. The amend runs the same facts again and refuses when they fail. The text of a card is not checked.

## Acceptance criteria

- [ ] A card without the required facts stays open after a move to decided, and the output names the missing fact and the command that adds it.
- [ ] The same card moves to decided after the printed command runs.
- [ ] A ghost whose held edges hold every fact can be set to decided; a ghost without them is refused the same way.
- [ ] An amend that removes a required fact is refused, and the card keeps its decided words.
- [ ] The contract check is a pure module with unit tests on the pure-file list.
