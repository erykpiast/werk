## What to build

Cross-tab memory is pulled, not pushed. The convos verb lists every conversation of the project with its session id and home card. The recall verb reads one sibling's session log from disk on demand, optionally filtered by a keyword. No tab is fed a diff of what changed since its fork.

The agent prompt tells the agent to read a card from the map with the show verb before it writes the card, so a stale context in its tab never leads to a wrong write.

## Acceptance criteria

- [ ] The convos verb prints each conversation's session id and home card.
- [ ] The recall verb prints the matching messages of a fixture session log.
- [ ] Focusing a tab sends no message about other tabs to its child.
- [ ] The agent prompt holds the read-before-write rule.
