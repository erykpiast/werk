## What to build

A chat pane sits beside the map. Enter in the composer sends the text, the pasted images, the open card from the location hash and the active conversation tab to the server.

The conversation manager runs one Claude Code child per conversation and speaks to it over stream-json. Each turn starts with a line that names the card the person looks at. The reply streams back over the live channel and renders through the same Markdown renderer and card link rule as a card body.

The agent prompt states the card wording rules: a card describes its subject and not the session, and names no file, function or line.

The server has a note route that appends a note to a card's thread and copies the `re #<id> "<title>": <text>` line to the clipboard. The browser never calls it.

## Acceptance criteria

- [ ] Enter sends one request that carries the text, any pasted image, the open card and the active tab.
- [ ] The fake agent's scripted reply appears in the pane piece by piece as it streams.
- [ ] The fake agent records that its turn input starts with the open card's id.
- [ ] The agent prompt holds the wording rules.
- [ ] A call to the note route appends one note event on the named card.
