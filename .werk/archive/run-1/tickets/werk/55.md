## What to build

Nothing builds after a plan until the person starts the run with `werk run <root>`. That start triggers the whole run. The build scheduler starts the builder loop for each unblocked ready ticket, one at a time, in the board's ready order. The merge loop and the agents make every column move.

A ticket whose builder loop ends green goes to merging. The merge loop makes a temporary tree of the main line's tip plus the ticket and runs the checks there. Red: nothing merges, and the ticket goes back to building with the failure. Green: the ticket merges onto the main line, with no integration branch, and goes to done. If the main line is checked out somewhere, the merge moves that checkout by fast-forward. Local changes that block the fast-forward stop the merge, and nothing moves.

After each merge, the merge loop runs the held-out set on the main line. A red step files a follow-up ticket in ready and puts a badge on the done ticket, and the merge stands. G2 for the subtree opens when every ticket of the subtree is merged and every held-out step is green. A later merge opens it again for the new tip.

## Acceptance criteria

- [ ] After a plan, no builder starts until `werk run`. Then every unblocked ready ticket builds, and the board moves each one through building, merging, and done.
- [ ] A ticket green alone but red on the main line plus the ticket goes back to building with the failure, and the main line does not move.
- [ ] A green ticket merges onto the main branch of the temporary repository, and no other branch is made for the run.
- [ ] A checkout of the main line with no local changes moves to the new tip. One with a local change that blocks the fast-forward stops the merge, and both the branch and the checkout stay where they were.
- [ ] A red held-out step after a merge adds a follow-up ticket in ready and a badge on the done ticket, and the merge stays.
- [ ] G2 opens when every ticket of the subtree is done and every held-out step is green. A later merge opens G2 again for the new tip.
