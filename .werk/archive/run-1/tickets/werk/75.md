## What to build

Several conversations run at the same time. A new conversation forks the parent session with the fork-session option, so it shares the cached prefix. A second, explicit control starts an empty conversation instead.

Each conversation stores its session id and its home card: the card open when it started. The home card names the tab and seeds the first turn. It is not a fence; the conversation may go anywhere.

The tab strip is the last row of the pane, below the composer, with real tabs flush to the pane edges. Each chip shows the home card id and a state dot. A '+' at the end forks at the open card.

On the map, a plain click moves the map and keeps the current conversation. Shift+click forks a conversation rooted at that card and focuses it. Shift+click on a card that already has a tab switches to that tab.

## Acceptance criteria

- [ ] Shift+click on a card adds a chip with that card's id, focuses it, and the fake agent receives the fork-session option with the parent session.
- [ ] Shift+click on the same card again focuses the existing tab and adds no chip.
- [ ] '+' forks at the open card, and the empty-conversation control starts a session with no parent.
- [ ] A plain click moves the map and leaves the active tab unchanged.
- [ ] The tab strip is the last row of the pane, and the first chip starts at the pane's left edge.
