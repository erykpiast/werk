## What to build

After the checks pass, a grader agent reads the pass's diff against each decided card in the ticket's depends_on closure. For each card it returns a score from 1 to 5, where 3 passes, and the gap between the diff and the card, with the file, line or test that shows it. A score under 3 on any card fails the pass, and the next builder pass gets the gaps with the brief.

## Acceptance criteria

- [ ] The grader gets one judgement line per decided card in the closure, not only per cited card.
- [ ] A fake grader score of 2 on one card fails the pass, and the next pass's prompt holds that card's gap.
- [ ] Scores of 3 or more on every card pass the grade step.
- [ ] The run's record holds each card's score and gap for the pass.
- [ ] The grader gets no judgement line for a card outside the closure.
