## What to build

A person starts a run on a plan. The first event of the run is a tier event, and the tier is always feature: G1, G2 and G3 each wait for the person, and no gate auto-passes. The run reads no tier from the conversation, and no run is re-rated. The run builds a ready ticket in its own worktree, made from a snapshot of the working tree. Each pass is a fresh headless agent that gets the brief, the decided cards in the ticket's depends_on closure, and the last failure cut to about 4,000 characters. When the agent exits, the loop commits the worktree as "pass n", then runs the ticket's checks itself; each check is one command and its exit code. A red check starts a new pass. Each pass writes one line to the run's record: check results, time and cost. Every time limit is a parameter.

On the board, a building ticket with a live session pulses and stops the moment the session ends. Its drawer shows a live preview of the session log above the slice, in a fixed-height scrolling area, which goes away when the ticket leaves building. All of it is tested at the command line against a temporary git repository with the fake agent.

## Acceptance criteria

- [ ] Starting a run writes a tier event with the feature tier before any other run event.
- [ ] No input, word or flag changes the tier, and no gate passes without the person.
- [ ] A scripted ticket whose first pass leaves a check red and whose second pass fixes it ends green after two commits, one per pass.
- [ ] The second pass's prompt holds the failed command and the end of its output, at most about 4,000 characters.
- [ ] The run's record has one line per pass with check results, time and cost.
- [ ] The loop's own check run decides the result, even when the fake agent reports green.
- [ ] A building ticket pulses while its fake session runs and stops when the session exits, and its drawer shows a live log that is gone after the ticket leaves building.
- [ ] A run stops at G1 until a person passes it, and the same at G2.
- [ ] A request text that names a tier ("just build it") does not change the tier, and no command re-rates a live run.
- [ ] A ticket green on pass 1 stops after one "pass 1" commit.
- [ ] Each pass starts a new agent process, and no agent lives longer than one pass.
