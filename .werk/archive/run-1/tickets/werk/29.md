## What to build

After a merge, a user path that must work does not work on the merged product. Make it work. Each path, word for word:

Scenario: A command-line test runs a werk command against a temporary project
Given a command-line test that uses the test harness
When the test asks the harness for a temporary project directory with a git repository
And the test runs a werk command against that project
Then the test reads the exit code of the werk command
And the test reads the output of the werk command
And any agent that the werk command calls is the scripted fake agent
And the temporary project is gone after the test ends

Scenario: A card added from the command line appears in an open page without a reload
Given a map with a root card "a" titled "Use an append-only log"
And the user opens the map in the browser
And the page shows card "a" in the refines tree
When the agent adds a card "c" titled "Fold is pure" from the command line
And the agent links card "c" to card "a" with a refines link from the command line
Then the page shows "Fold is pure" under "Use an append-only log" in the refines tree
And the user did not reload the page

Scenario: A page control changes a card only by appending an event
Given a map with a card "a" titled "Use an append-only log"
And a card "b" titled "Cards fold from it" that refines card "a"
And the user saves a copy of the log
And the user opens card "b" in the browser
When the user uses a control on the page that changes card "b"
Then the log has exactly one more event than the saved copy
And the start of the log is byte-for-byte the same as the saved copy
And the page redraws card "b" from the new state of the map
And `show` for card "b" prints the same state that the page shows

## Acceptance criteria

- [ ] A user can follow "A command-line test runs a werk command against a temporary project" from start to end
- [ ] A user can follow "A card added from the command line appears in an open page without a reload" from start to end
- [ ] A user can follow "A page control changes a card only by appending an event" from start to end
