## What to build

The serve verb starts one server per project directory. It takes a lock: a second start on the same project waits up to 5 seconds for a live holder, then refuses with the holder's pid. The listen retries every 250 ms, up to 20 times, when the port is busy.

The server serves the React client, transformed by Vite, a read API that returns the fold, and one live event channel. When the log changes, the channel pushes "changed", and the client refetches the graph.

The map view draws the refines tree of the fold, with the open card in the location hash. No view edits a drawn card in place.

The browser test harness boots the real server on a copy of a fixture project, with the fake agent first on the PATH. It blocks outside script hosts, clears local storage, and saves a screenshot per test as evidence. Tests assert on structure.

## Acceptance criteria

- [ ] The map shows the cards of the fixture project in their refines tree.
- [ ] An add and accept from the command line while the page is open makes the new card appear with no manual reload.
- [ ] Opening a card puts its id in the location hash, and a reload opens the same card.
- [ ] A second serve on the same project prints that it waits, then refuses within about 5 seconds.
- [ ] The card view has no control that edits the card's text.
- [ ] `make e2e` runs the browser specs and keeps one screenshot per test.
