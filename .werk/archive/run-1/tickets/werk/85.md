## What to build

The overseer watches every build pass that werk starts, from its event stream. It acts on three signs. A permission ask that nobody answers: the overseer answers it. No new event for the silence limit (60 seconds by default), with no tool call in flight: it cancels the session, and a fresh pass starts. A loop: every 5 minutes by default, a classifier agent decides whether the agent repeats itself with no progress, and on a yes the session is cancelled after one warning.

Both limits are parameters, so tests set them to milliseconds and use the fake agent.

## Acceptance criteria

- [ ] A fake agent that emits a permission ask gets an answer and continues.
- [ ] A fake agent that goes silent past the limit is cancelled, and the builder starts a new pass.
- [ ] A fake classifier that answers "looping" makes the overseer warn, then cancel the session.
- [ ] A tool call still in flight past the silence limit is not cancelled as silence.
