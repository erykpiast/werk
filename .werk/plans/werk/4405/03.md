## What to build

A test asks the harness for a fresh project: a temporary directory with a git repository and an empty map, plus a temporary target repository. The test runs werk commands against it and reads each exit code and its output. When the test ends, pass or fail, the harness removes the directories and stops anything it started.

Before the first test, the unit run removes every environment variable that points at a real project and makes Bun's spawn, program lookup and shell default to the cleaned environment. The fake agent is first on the program search list under the real agent's name, so every process a test starts finds the fake.

The fake agent reads one script per temporary project: an ordered list of steps (an event to print as one line of the agent's output stream, or a file to write inside the project) and an exit code. A file path that leads outside the project fails the step and writes nothing. An ask step prints a permission request and does not wait; the turn waits for open asks only before its final result, and a crash with an ask open exits with no result. Each pause adds a 20 ms margin. Each launch records its arguments and the role read from its environment. With the role chat, the fake plays one scripted reply per input message and exits when input closes; with any other role it plays one reply and exits with the script's code, treating a permission answer as part of that reply. With no script it exits with an error.

## Acceptance criteria

- [ ] A test gets a fresh project with a git repository and an empty map, and it is removed after the test, also when the test fails.
- [ ] A child process started with no explicit environment finds the fake agent, not the real one.
- [ ] No variable that points at a real project survives into a test or its children.
- [ ] A scripted edit outside the project fails and writes nothing.
- [ ] An ask step does not block the steps after it, and a crash with an open ask prints no final result.
- [ ] Each launch is recorded with its arguments and role.
- [ ] A chat-role fake answers two messages in turn and exits when its input closes; a builder-role fake exits after one reply.
- [ ] The fake with no script exits with an error.
