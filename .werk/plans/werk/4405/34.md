## What to build

When a build of a ticket starts, a step author with the role heldout-author and no tools writes Given/When/Then steps from the ticket's brief and decided cards. The program stores them in werk's store, outside the builder's worktree, with the version of each source card. A follow-up ticket gets no step author.

A held-out run binds and runs the steps of merged tickets only, on the main line's tree. The binder, role heldout-binder, works in a temporary worktree of that tree, maps each step to UI actions and assertions in its own test folder, and never changes step text or makes a test pass; it fixes only its own errors and reports, for an element not found, whether it thinks it is a binder error or a missing feature. Its whole report is void if it changed any file outside its folder, comparing paths as stored. The product's browser test run also finds tests in the binder's folder, so a step runs on the same server, fixture and fake agent as a product spec; a builder's checkout has no such folder. The binder's time limit grows with the step count.

Each step ends green, red or not run; a binder failure, timeout or unbound step is not run and files nothing. Before a run, each step whose source card changed since it was written goes back to the step author, who rewrites or drops it. On a red step the builder's next brief gets only the failed step's text. `werk gate <subtree-id>` shows G2 waiting until every held-out step is green, and `werk gate <subtree-id> approve --actor you` passes it only then.

## Acceptance criteria

- [ ] A build start launches a step author, and its steps are not readable from the builder's worktree.
- [ ] A scripted binder writes a test into its folder and the browser run on that tree finds and runs it.
- [ ] A binder that edits a product file voids its report.
- [ ] A binder timeout shows its steps as not run, not red.
- [ ] A step whose source card was retitled is sent back to the author before the run.
- [ ] G2 approve is refused while a step is red or not run, and passes when all are green.
