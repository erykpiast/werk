## What to build

`make build` compiles the server, its packages, the Bun runtime and the Vite-built client into one executable for macOS and Linux, each on ARM and Intel. The build writes a list of werk's own files (client assets, prompts, shipped subagent definitions) and embeds them; the code reads that list and never discovers its own parts by listing a folder. The same code runs from a checkout and from the executable. Every child process werk starts, every prompt that names werk, and every command it prints names the running executable, never a runtime and a source path. The user's own files are read from disk as before. No Homebrew tap or release step is built; the executables are the files a later install channel points at.

## Acceptance criteria

- [ ] The executable, copied alone into an empty folder, serves the map and the client for a fixture project.
- [ ] A prompt built inside the executable names the executable's path for werk commands.
- [ ] The code has no folder listing of werk's own files; a test fails if one is added.
- [ ] `make build` produces the four platform files.
