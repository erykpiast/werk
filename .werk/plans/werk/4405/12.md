## What to build

Each conversation keeps a chat log beside the decision log, one line per message with speaker, time, session id and kind; this ticket defines the reader of that log (the chat pane later writes it). `werk quote <card> <conversation> "text"` counts every occurrence of the text in every spoken message of that log; tool calls, tool results and tooling text never count. With exactly one occurrence it writes, in one event, an excerpt ghost and its held supported_by link from the citing card. The excerpt keeps conversation, session, message position (counted over all lines, hidden ones too), span, speaker, time and the quoted words. Otherwise it fails, writes nothing, and says which case it found: no match, a match in N messages, or N matches in one message.

A plain add of an excerpt refuses. A retitle or text edit of an excerpt refuses, before and after accept; a note is allowed. Accept or discard of the citing card takes the excerpt with it.

## Acceptance criteria

- [ ] A unique quote creates one excerpt ghost with the right message position and span, linked from the card.
- [ ] A quote found in two messages fails and names 2 messages; a quote repeated in one message fails and names 2 matches.
- [ ] Text present only in a tool result gives no match.
- [ ] Adding an excerpt by hand is refused; editing an excerpt's words is refused.
- [ ] Discarding the citing ghost drops its excerpt.
