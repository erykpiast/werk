## What to build

On the board a person drags tickets within ready to reorder them. Inside an active run, the trigger icon on a ready ticket, or a drag from ready into building, starts that ticket's build early; it joins the run's merge loop, which still builds at most three at once. The drag into building is the only manual column move. Without an active run, the trigger is disabled.

Archive is a button in the drawer header of a ready, blocked or building ticket, never of a merging or done one. It asks for confirmation and says the ticket is never deleted for good and can be restored. Archiving a building ticket ends its build: the builder loop reads the board about once a second, and when it finds its ticket archived it stops the agent, commits nothing of the pass, runs no checks, records no retry, removes the worktree folder and keeps the branch. Nothing of that build merges, even a green last pass; the merge loop goes on with its other tickets. Cancelling the confirmation writes nothing. An archived ticket can be restored to the column it left. Every action is a write with the token.

## Acceptance criteria

- [ ] Reordering ready tickets changes the order in which the run builds them.
- [ ] The trigger on a ready ticket inside a run starts its build; outside a run it is disabled.
- [ ] Archiving a building ticket stops its agent within about a second and its branch remains.
- [ ] Other tickets of the same run keep building after an archive.
- [ ] Cancelling the archive confirmation leaves the board log unchanged.
- [ ] A merging or done ticket shows no archive button.
