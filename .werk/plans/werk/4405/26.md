## What to build

`werk ticket-check <folder> --root <card-id> --spec <file>` reads every Markdown file in the folder, the decided real cards under the root (the root and its refines descendants with status decided; ghosts do not count), and the story numbers of the spec's User stories section.

A pure parser reads the fixed ticket format: the header lines title, cites, blocked_by, stories and touches in that order, then the sections What to build, Acceptance criteria and Checks. Eight own checks run on each file alone: title, shape (each missing line or heading named), size (4000 characters or fewer), what-to-build has text, acceptance has a bullet, no file paths (a token with a slash between name characters ending in a file extension, or a files line; each path listed with its line number), make-targets (each Checks bullet is `make <target>`; an empty section passes), touches (at least one name, none holding a slash or backslash or ending in an extension). A file with no title is not parsed further.

Three set checks run over the tickets that passed their own checks: every decided card under the root is cited by some ticket; every story is delivered by some ticket and no ticket names an unknown story; every blocked_by number is a ticket in the set and the graph has no cycle. Cites accept ids with or without a hash.

Output is one line per failure, `<ticket file>: <check>: <field>: <message>`, with `ticket set` when no ticket owns the failure, then a count line. Exit 0 when nothing fails, 1 when a check fails, 2 for a malformed call (missing flag, folder or spec, a spec with no User stories heading, a root not in the map).

## Acceptance criteria

- [ ] A folder of valid hand-written tickets exits 0 and prints the count line.
- [ ] A ticket naming a source file path fails no-file-paths with the line number; a bare file name passes.
- [ ] A ticket over 4000 characters fails size.
- [ ] An uncited decided card, a missing story and a blocker cycle each print one set failure and exit 1.
- [ ] A ghost under the root does not need to be cited.
- [ ] A missing spec file exits 2.
- [ ] The parser and the checks are pure modules that pass the coverage gate.
