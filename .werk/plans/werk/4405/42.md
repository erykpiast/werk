## What to build

A GitHub Actions workflow runs on each push to the main line and on each pull request. It installs the pinned Bun, installs packages from the lockfile only, runs lint, typecheck, test with coverage and e2e through the make targets, builds the executable for one platform, and starts it once to check that it serves a map. A red run does not undo the merge. The run's result is what a later release step requires of a commit before it can be tagged; no release step is built here.

## Acceptance criteria

- [ ] The workflow runs every make check on a clean machine from the lockfile.
- [ ] It builds the executable and a start of it answers a map request.
- [ ] A lockfile that misses a package makes the run fail.

## Checks

- `make lint`
- `make typecheck`
