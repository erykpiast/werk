## What to build

The right pane holds the chat. A conversation has one long-lived Claude Code child speaking stream-json, with partial messages on, the permission prompt tool on stdio, auto permission mode, and the werk instructions appended. A message is sent with a turn name and the token; a request without the token starts nothing. Each turn begins with the open-card line: the full card when the open card changed since the last turn, otherwise a one-line "still on #id — title" reminder; the whole tree names the home card.

The server keeps sent turns in order and attributes each streamed part to the oldest open turn; the end line with duration and cost closes it. The pane draws a sent message at once; a message whose turn has not started shows "waits for the reply above". If the agent exits, every open turn ends. A part for a turn this page did not send starts a new turn. Streamed tokens are ephemeral; each finished block replaces its streaming form and is written to the conversation's chat log. The header row above the composer shows thinking or the running tool, seconds and tokens.

Replies render as Markdown with live card links. A run of tool calls collapses into one line that shows the latest call and a count; opening it shows each call with its input and output. When the agent writes to the map, the map redraws from the changed signal.

## Acceptance criteria

- [ ] With a scripted fake chat agent, a sent message streams a reply into the pane under that message.
- [ ] A second message sent while the first reply streams shows the waiting mark, and the rest of the first reply lands above it.
- [ ] The first turn on a card carries the full card; the next turn on the same card carries the one-line reminder.
- [ ] A fake reply that writes a card makes the map show it in the same turn.
- [ ] Three tool calls in a row show as one collapsed line with a count.
- [ ] A chat request without the token starts no agent.
