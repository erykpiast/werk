## What to build

After each merge the held-out set starts on that merge's commit in the background, with the steps of every merged ticket including the one just merged, and the merge queue takes its next ticket at once. An older held-out run is not stopped by a newer merge; each result belongs to its own commit, and only the result on the main line's final tip opens G2. A held-out result event records each step's state on the done ticket whose merge it followed.

A red run groups its red steps by source ticket and files one follow-up ticket per group, citing the cards of its source ticket, with the steps as its stories, its own retry cap, and no step author. A red step that an open follow-up already carries files nothing. The merge stands. A binder error files nothing; an error that stays at the end of the run ends it waiting for a person. The red badge stays on the merged ticket after its follow-up goes green.

## Acceptance criteria

- [ ] A merge starts a held-out run and the next merge does not wait for it.
- [ ] Red steps from two source tickets file exactly two follow-ups, each citing its own ticket's cards.
- [ ] A step that is red again while its follow-up is open files nothing.
- [ ] G2 opens only on a green held-out result for the final tip.
