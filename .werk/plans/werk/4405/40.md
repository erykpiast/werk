## What to build

A decided map card carries a Build button. It works only when the plan's scope holds no open or proto card; otherwise it is grey and names the blocking cards. A press starts one detached process with no time limit that plans the subtree and then runs the merge loop; it outlives a server restart.

Below the columns, each planned subtree has one persistent plan card, at most four lines high, linked to its subtree on the map and from each of its tickets. It is coloured by state: creating (pulsing, naming the running step), building, done, or stopped with its reason; a plan whose process is gone without an end shows stopped. Its drawer shows both writers' logs, then the whole spec, its tickets and how the last plan ended. While a plan runs, the subtree root on the map carries a marker linking to the plan card.

A subtree with unfinished work (a ticket in ready, blocked, building or merging) offers Resume, which restarts the merge loop, and a confirmed Restart, which cancels running builds keeping their branches, archives every unfinished ticket, keeps done ones, and plans and runs again. Both the map card and the plan card show the same control for the same state. Every start of a plan or run, from the board or the command line, refuses while a run is in progress on the subtree or an ancestor and names the blocking run; disabled controls say so and link to its plan card. The command-line restart prints each build it cancels and each ticket it archives and needs a confirmation flag.

The server watches each build process it started and, at its own start, every build with a start and no end: a dead one gets an end with the reason died, and a fresh pass starts from the branch's last commit with the death in its brief, counting against the cap.

## Acceptance criteria

- [ ] Build on a decided card with a scripted plan creates tickets and merges them with no further press.
- [ ] Build is grey on a card whose scope holds an open card, naming it.
- [ ] A subtree with unfinished work shows Resume and Restart, not Build.
- [ ] A start on a child of a running subtree is refused and names the running subtree.
- [ ] A killed build process gets a died end and a fresh pass after a server restart.
- [ ] The plan card shows the spec in its drawer.
