## What to build

The shared Claude Code settings in the repository allow every make target and the werk command line, and ask for the accept, remove and restore operations, so a personal file cannot turn those questions off. The shared file allows nothing that writes outside the repository or reaches the network. The repository's ignore list names the personal settings file.

One hook runs after an agent writes or edits a source file: it formats and lints that file only, applies the safe fixes, and returns the remaining errors to the agent without blocking the edit.

The repository's subagent folder holds a link to each subagent that werk ships, not a copy. A check fails when a shipped subagent has no link or a file under its name is not a link. The repository defines no project skills and no MCP servers.

## Acceptance criteria

- [ ] An accept command still asks under the shared settings, and a make target runs with no question.
- [ ] After an edit that leaves an unused import, the hook removes it and returns nothing.
- [ ] Replacing a subagent link with a copy fails the check.
- [ ] The repository has no skill definitions and no MCP server entries.

## Checks

- `make test`
- `make lint`
