## What to build

A GitHub Actions workflow runs on each push to the main line and on each pull request a person opens. It installs the pinned Bun version and the locked packages from a clean state, runs lint, typecheck, test with coverage and e2e, builds the executable for the runner's platform, and starts it once to see that it serves its map. A red run blocks a release of that commit and does not undo the merge.

## Acceptance criteria

- [ ] The workflow runs every check target and the executable build on a push to the main line.
- [ ] The workflow installs the Bun version that the repository pins.
- [ ] The started executable answers a read of the map before the run ends green.

## Checks

- `make lint`
- `make test`
