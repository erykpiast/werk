## What to build

A build target compiles the server, its packages, the pinned Bun runtime and the client that Vite built into one executable file for each of macOS and Linux on ARM and Intel. The build writes the list of werk's own files (client files, prompts, subagents and command modules) and puts the files inside the executable; werk reads that list and never lists a folder to find a part of itself. A child process, an agent prompt and a command shown to a person name the executable that is running, never a runtime and a source path. The build writes a checksum beside each file. No tap, tag or publish step is part of v0.

## Acceptance criteria

- [ ] The build target makes four executables and a checksum for each.
- [ ] The executable for the build machine starts from an empty folder, serves the client, and lists every command in its help.
- [ ] The agent launch options from the executable name the executable's own path.
- [ ] No code path that finds werk's own files reads a folder listing.
