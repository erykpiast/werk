## What to build

v0 starts as a new git repository whose main line holds no files. This ticket sets up the project root so a person or an agent can work from the repository alone.

A person runs `make` with no target and sees every task with a one-line description. Each target first compares the installed Bun with the pinned version and stops with both versions and the install hint on a mismatch. Each check target installs the locked packages first, only when the package file or the lock file changed, and never changes the lock.

The check targets call package scripts: lint runs Biome over all code with the recommended and React rules, and a fix target applies its safe fixes. Typecheck runs the TypeScript 7 compiler in strict mode with checked index reads and no output. Test runs the unit tests under the Bun test runner on four parallel workers with a 15 second default limit per test. Test-coverage runs the same tests with coverage. E2e runs the Playwright test runner and passes while no spec exists. A `check` target runs all checks in the order the merge loop runs them, and a `dev` target exists for the dev server that a later ticket fills in.

The README says what werk is and how to install and start it. AGENTS.md holds only how to start werk, which target runs each check, where server and client code live, that decisions go on the map, and that an agent lists the build-rule cards and follows them. CLAUDE.md is one line that imports AGENTS.md. Nothing is copied from the prototype.

## Acceptance criteria

- [ ] `make` with no target prints every target with its description.
- [ ] With a Bun version other than the pinned one, every target stops and prints both versions and how to install the pinned one.
- [ ] On a fresh clone with no installed packages, `make test` installs the locked packages and passes.
- [ ] `make lint`, `make typecheck`, `make test`, `make test-coverage` and `make e2e` each exit 0 on the new tree.
- [ ] A file with a type error on an unchecked index read fails `make typecheck`.
- [ ] A one-line rule waiver without a reason beside it fails `make lint`.
- [ ] A unit test that sleeps 8 seconds passes, and one that never resolves fails after about 15 seconds.
- [ ] CLAUDE.md holds exactly one import of AGENTS.md.
