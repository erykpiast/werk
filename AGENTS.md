# Working on werk

- Start: `make dev` starts the dev server. `make` lists every task.
- Checks: `make lint`, `make typecheck`, `make test`, `make test-coverage`, `make e2e`. `make check` runs all of them.
- Code: the server is TypeScript under `src/`. The client is React under `client/`.
- Decisions go on the map. Record each one as a card before you build on it.
- Before you start, list the build-rule cards and follow every one.
